# 表示担当への指示（研究結果確定後のみ実行）

これはLuna向けの仕事です。Luna agentは呼び出していません。
現時点では深い比較が進行中です。最終ASTRA_HANDOFF.jsonとanalysis.mdの
確定checkpointを待ってください。新解析・閾値変更・候補昇格はしないこと。

## 作るもの

既存exporterを使う短い分岐KIFとHTML。旧成果物は上書きしない。
表示は4組程度に絞る：

1. ▲2四飛後の△2三歩：静かな候補が生成器に入った理由と比較値。
2. ▲3六飛後の△6七角成：旧候補との比較。確定していない最善認定はしない。
3. ▲3五飛→△6七角成：▲同金・▲7九金・▲8七金と最善級応手。
4. ▲2四飛→△6七角成：▲同金・▲7九金・▲8七金・▲2一飛成と最善級応手。

各分岐は、候補・相手応手・罠を説明する最短の継続を表示。
`display_prefix`は上限目安。必要のない長い最善PVを追加しない。
詰みPVは任意の詳細枝へ。通常探索の詰み表示と、全受けの証明書を混同しない。
`mate_proof_checks.json`がcertifiedでなければ、最短19手や厳密な強制詰みを
断定しない。最終handoffに従って未確認・不一致の注意書きを付ける。

## 変更してはいけない意味

- 評価値の正負は常に先手視点。CPとmateを換算しない。
- 深い順位・差は、保存された同一予算の比較対象内の値。
- 動機タグは「思いつく理由」であって、指される確率や正しい防御ではない。
- ▲7七角打への入口の自然さと、その先の戦術的被害を別表示。
- benchmark例と診断用に残した既存rejectを分ける。actual候補へ自動分類しない。
- 元の△3二銀など3例のreject判断を変更しない。既存表示へのリンクでよい。

研究結論はAstraの最終handoffをそのまま用い、不足があればAstraへ質問。
KIF合法性・分岐・コメントを検査し、表示checkpointをcommit/pushしてSTOP。
