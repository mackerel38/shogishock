## 分布と偏り

対局時ratingは双方合計1,224観測、欠測0、最小913 / 中央値1706 / p90 2131 / 最大2505。
`<1200:103, 1200–1599:375, 1600–1999:497, >=2000:249`。
同一人の複数対局を含む**参加機会の分布**であり、プレイヤー等重みのrating分布ではない。

time controlはraw clock/byoyomi/increment/daysを保持。APIのspeedは全件欠測なので推測値で埋めていない。
参考としてclockの`totalTime`秒を独自区分すると、`<180:66, 180–599:158, 600–1799:228, >=1800:80`。
別にcorrespondenceが80対局（13.1%）。これは公式speed分類ではない。
通信対局は考慮時間や定跡利用条件が異なるため、即時応手のHuman Policy用途にそのまま混ぜる限界がある。

## Reach DB

`data/human_pilot.sqlite3` に元ゲーム、採否理由、局面、occurrencesを保存。
canonical identityは盤面・手番・持駒。左右反転は統合しない。
同一ゲーム再訪はゲームreach分子1票、着手分布では各意思決定を別観測にする。
プレイヤーreachはその局面へ到達した対局の**双方の参加者の集合** / 全457プレイヤー。
親→子edgeの通過ゲーム数 / 親に到達したゲーム数をconditional reachとして別保存する。
Wilson区間はiid-game仮定の参考値で、プレイヤー依存や標本枠の偏りをカバーしない。

局面支持数は中央値1、p90も1、最大612。したがって9割以上のexact局面は1ゲームしか観測されていない。
到達頻度は中央値1/612=0.1634%、p90も同じ。数字だけで「この局面は実戦で稀」と確定しない。

探索元は人間DB全局面ではなく [テラショック浅部](../terashock_seed_audit/analysis.md) に変更した。
0–12ply bookの30,421局面のうち、標本内観測は1,119、10ゲーム・10プレイヤー以上の支持は56。
16/20plyに広げても十分支持のある局面は56のままだった。12plyを主universeとする。

## 利用条件と保存

[Lishogi公式API案内](https://lishogi.org/developers) と [利用規約](https://lishogi.org/terms-of-service) を確認し、
公式APIによる少量ローカル教育・研究利用として取得した。包括的データ再配布許諾とは解釈していない。
request URL、取得UTC、payload hash、規約URL、rawメタデータを `data/human_raw/human_pilot` に保存。
raw/個人識別子付きDBは公開していない。81Dojo等への自動収集は行っていない。

次の標本改善は、公開チーム以外へのcoverage、期間内の時間層別抽出、通信対局とリアルタイム対局の分離、
駒取り・取り返し局面の支持の確保。件数だけ増やしたり、巨大NNへ進んだりする段階ではない。
