# Pass pilot反証診断とreach prototype — 2026-09-08

## 結論

pass sensitivity単体での上位選別は、明白な駒取り・取り返しを無視したfalse positiveを大量に拾う。
relativeでも解消しない。さらに「合法な良応手が1手しかない」ことも、その1手が明白な取りなら有効な奇襲根拠にならない。
passは即時対応要求のcheap featureへ降格し、実戦reach・元局面の有用性・明白な良応手診断を先に導入する。
今回は新奇襲を発見したとは主張しない。大量deep・新scan・Human Policy・Vast.aiは未実施。

## 対象と測定方法

保存済みschema-5 `reports/pass_pilot` の148局面・6314候補のみを使用。normal/pass各10k。
旧bound診断・warmup・serial partialを混ぜていない。
先後別raw top30 / relative top30の和集合は先手49、後手46、計95候補。
全95件の候補前後SFEN、手順、normal first reply、取り属性、parent評価、応手評価とPVを照合し、下記の型を確認した。
先後別 [先手HTML](report_sente.html) / [後手HTML](report_gote.html) に全95候補の盤面・応手・保留理由を掲載。

明白な応手proxyは候補駒の取り・取り返し・歩接触取り・局所material回収。
各候補の該当応手と必要なnormal PV先頭の比較用応手を10kで評価（計242応手）。
部分解析の基準はroot評価と解析済み応手後評価のうち受け側最良値。
基準との差が100cp以内なら `obvious_reply_neutralizes`。50/200/300cpも併記。
これは人間実測のfalse-positive率ではなく、heuristicと浅い探索に条件付けた「明白な良応手で反証された率」。
未反証候補を本物の罠とは扱わない。探索地平差・未解析応手により判定は変わり得る。

## 少数100k確認：狭い応手幅だけでも不十分

各側についてraw最大、relative最大、候補損失最小、ply最小から重複を避け4候補を事前ルールで選択。
無作為抽出ではない。8候補のrootと全340合法応手を100kで確認。1Mは未使用。

|後手 `0a33fbe73571830519e4_2b6f`|5|-54|+2793|6753|8h6f|+2803|1 / 31|

以上5例はCP比較可能で、50/100/200/300cpの全基準で良応手は1手。その唯一手が明白な駒取りであり、すべてneutralizes=true。
5/5という確認結果を母集団の率とは扱わない。
残り3例はrootまたは応手集合にmate評価が混在し、CPによる幅・neutralizesは保守的に未確定とした。

- `98a0e8226d03eff3b7e9_7h8g`: 100k rootはmate -13。CPへ変換して率計算しない。
- `a77ad58c704df8bb27bf_7g3c+`: 元局面+126、候補+57、pass 5860。通常の角交換に対する4b3cは+352。高passでも「取り返さない」仮想の効果が大きい例。
- `b1d901d7811d5a04a762_3c7g+`: 元局面-132、候補-120、pass 5178。6h7gは+144。これも取り返しを無視するpassの問題を示す。応手集合にmateがあり、幅は未確定。

95件を通覧すると、先手の8h4d→2b4d、B*7a/B*7cへの金銀桂の取り、後手の2b6f→8h6f/7g6f、3b2c→2f2c+等の反復が目立つ。
rawでは既存の大きな有利や飛車の侵入への対応要求、relativeでは差し出した角等の取りが目立つ。
「候補が静か」でも「相手の明白な取りをpassさせただけ」の場合がある。quietタグだけでは解消しない。

## Reach-frequency prototype

公式APIから46件、宣言BOT/AI等を除き19対局、0–40plyで708局面。
ゲームID重複排除、全手順合法性検証、同一ゲーム再訪のreach重複排除、手順前後統合を実装。
左右反転は統合していない。source/game ID/取得日時/利用条件URL/rating/time control/BOT flag/movesを保持。

標本内では初期局面19/19、7g7f後11/19、7g7f 3c3d後7/19、さらに6g6f後5/19。
これは2アカウントの標本内比率であり、人間全体の序盤分布ではない。
上位95候補で親局面が一致したのは `0a33fbe73571830519e4_2b6f` のみ。
未観測は標本内0、母集団reachはunknownとして分離する。
[出典と利用条件](SOURCES.md) を参照。raw棋譜・SQLiteはローカル保管し、再配布の許諾は確認済み扱いにしていない。
