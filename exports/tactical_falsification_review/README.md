## 比較の読み方

人間に自然そうに見えるかどうかと、エンジンが実際に十分良いと評価するかどうかを別々に確認しています。対照例では、自然そうな取り返しが最善級の応手より1931cpまたは2328cp悪いため、自然に見えることだけでは候補手を除外していません。
